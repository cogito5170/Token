## screen: live_monitor — 지금 일꾼들이 무엇을 하고, 서로 어떻게 돕고 있나? (자세히)

화면 하나, 페이지 · 탭 · 표 없음. 어두운 무대 위에서 장면이 움직인다. 아래는 한 순간의 정지 화면이고, 글자는 영어 단어 하나뿐이다.

```
┌────────────────────────────────────────────────────────────────────────────────┐
│  ▢ ▢ ▢   ← 기다리는 타일 (대기 선반)                                              │
│                                                                    ┊ 실패 선반  │
│          ◯ ·:·  build                 ⬡                            ┊  ◩ (갈라진 타일) │
│        (입자 = 턴 실행 중)          ╱ ╲  (π 굵은 선)                ┊            │
│               ╲   ∙→→→∙  talk     ╱   ╲                                        │
│                ╲━━━━━━━━━━━━━━━ ▢ ┄┄┄┄ ◇ wait (흐림 + 팽팽한 줄)                  │
│          ( ◯ 둘레 고리: 닫힘 = 통과 / 톱니 = 실패 / 열림 = 판단 필요 )               │
│ ──────────────────────────────────────────── 수평선 = 전체 사용 / 예산 ─────────── │
│  ■ ■ ■ ■   ← 끝난 타일 (완료 선반, 채워짐)                                         │
│                                         ⏵ ━━━━━━━●━━━━━━━  (재생 스크러버, 호버 시만)│
└────────────────────────────────────────────────────────────────────────────────┘
```

- figure 모양 = 역할(원 · 둥근 사각 · 육각 · 삼각 · 마름모 · 알약), 크기 = 이번 작업에 쓴 양, 밝기 = 활동.
- 움직임: 펄스가 선을 따라 이동(메시지), 숨쉬기 템포(경과 · 긴장), 입자(턴 안의 활동), 타일 비행(작업 맡음 · 끝남).
- 분위기: 막히면 장면 전체가 느려지고 어두워지며 `wait`, 다 끝나면 정렬되고 한 번 빛이 쓸고 `done`.
- 마우스를 올리면 작은 mono 툴팁(역할 · 작업 id · 토큰 · 비용 · 경과). 그 밖의 숫자는 없다.
- 움직임 줄이기: 이동 · 숨쉬기 · 입자를 끄고 모양만 즉시 바꾼다(design/motion.md 7).
