# ADR-0006 인증

- 상태: 채택
- 결정: 이메일 + 비밀번호(Argon2id). 액세스 JWT 15 분(HS256, `GC_JWT_SECRET`) + 불투명 리프레시 토큰 30 일(httpOnly · Secure · SameSite=Strict 쿠키, DB 에는 sha256, 회전 + family 재사용 감지). 역할은 워크스페이스 단위(admin · developer · viewer).
- 이유: MVP 에 외부 IdP 의존을 두지 않는다. 짧은 JWT 는 DB 조회 없이 검증되고, 리프레시 회전과 재사용 감지로 탈취 피해를 줄인다. 팀 SSO(OIDC)는 나중에 identity 도메인 안에서 추가한다(사양: 팀 권한 세분화는 나중).
- 결과: SSE 는 쿠키 또는 60 초 `sse_token` 으로 인증(api-contract.md 2 절). 자세한 매개변수는 security.md 6 절.
